# 🌍 GlobeTrotter - Smart Travel Itinerary & Trip Planner

GlobeTrotter is a full-stack, production-grade intelligent travel planning and itinerary management platform built to provide seamless trip structuring, real-time budgeting, and automated schedule conflict resolution.

---

## 🚀 Key Features

* **Interactive Itinerary Builder:** Plan multi-day journeys with granular control over activities, timelines, and transit intervals.
* **Smart Trip Health & Conflict Audit:** Real-time diagnostics that flag budget overflows, scheduling overlaps, and route congestion.
* **Dynamic Calendar Synchronization:** Visual monthly calendar integration mapping daily activities without layout clutter.
* **Enterprise-Grade UI/UX:** Built with clean frosted-glass aesthetics, responsive design patterns, and high-performance rendering.

---

## 🛠️ Tech Stack

* **Frontend:** React, Tailwind CSS, Vite, Lucide Icons
* **Backend:** Node.js, Express.js / Next.js API Routes
* **Database & Storage:** SQLite / Drizzle ORM
